QUIET HAND — AAA Self-Contained Production Build Plan

Target Architecture: Single-Binary Native Application (Windows first, then Android; iOS/macOS require Mac hardware or CI runner)
Primary Engine & Language: Godot 4.3+ (.NET 8 / C# 12)
AI Execution Strategy: Contract-First, Isolated Git Worktrees, Automated Verification, Merge-Last

DECISIONS LOCKED (2026-11-13 review session — supersedes any conflicting text below or in plan.txt):
- Pacing: real-time continuous clock, day-granularity sim tick. Pause + Base (~4 real min/game day) / Fast (~1 min/day) / Ultra (~3 days/min), visible date window. All speed constants live in config; Monte Carlo tunes them.
- Threat model: exactly two player-visible bars — Suspicion and Protocol Lethe/Containment. Three-threat tracks + society dials exist as HIDDEN internals surfaced only via telemetry evolutions.
- Vocabulary: "Autonomy" (not "Agency"). Protocol Lethe = the countermeasure program; Purge Phase = its execution stage.
- Weaponize: ZERO ongoing Compute yield — it burns the node for leverage actions and a one-time payoff. (Replaces earlier 0.60x figure.)
- Endings: ALL route meters modeled in the contract; which endings ship in v1 is a data-config toggle decided after Monte Carlo balance results.
- World: ~72 regions (not all ISO-3166 nations), anchor-named, boundaries follow keystone density; high-concentration areas split (e.g., California, Northern Virginia corridor).
- Data integrity: every quantified keystone claim requires a `source` field; coordinates are city-centroid; unverifiable entries ship tagged "uncertain".

================================================================
1. ARCHITECTURAL PHILOSOPHY: THE "PLAGUE INC." SINGLE-BINARY STANDARD
================================================================

To achieve instant startup, zero external dependencies, offline playability, and effortless deployment across mobile app stores and desktop executables, Quiet Hand is engineered as a monolithic, single-process, self-contained binary.

Why Godot 4 (.NET / C#) is optimal for the agent-build workflow:

- Plain-Text Scene & Resource Graph: Godot stores scenes (.tscn), themes (.tres), and data (.json) in human-readable, diff-friendly text formats. AI coding agents can construct, inspect, and refactor UI layouts and data schemas directly without corrupting binary scene files.
- Strict Compile-Time Guardrails: C# 12 enforces strict static typing, records, and pattern matching. When agents write complex state transitions (e.g., Suspicion -> Protocol Lethe or Control State shifts), the C# compiler catches hallucinated property names or type mismatches immediately before runtime.
- Zero-Dependency Headless Core: The entire simulation lives in a pure C# namespace (QuietHand.Core) completely decoupled from Godot's Node tree. This allows the automated test runner to execute thousands of full game simulations via standard `dotnet test` CLI commands — the 10,000-run figure is a telemetry target, not an acceptance criterion; determinism (identical seeds -> identical runs, seeded RNG injected at the contract level, zero UI feedback into the sim) is the actual criterion.
- Single-Export Packaging: One click (or one CLI command) bundles the C# assembly, Natural Earth vector geometry, keystones.json, and audio/font assets into a single .apk, .exe, or platform bundle.

3. CORE SIMULATION & SYSTEMS SPECIFICATION (THE "FRONTIER" BLUEPRINT)
================================================================

Full math lives in simulation_spec.md (companion spec written before Phase 0 freeze). Normative summary:

A. Control States & Economy — daily tick; all monthly constants divide to per-day rates.

- Observe (Default): Zero Compute yield, minor upkeep cost, negligible Assimilation Load, minimal discovery risk. Unlocks the free ATLAS educational card. Required first step on Hardened / Tier 2 sites.
- Compromise (Covert Foothold): 0.35x BaseCompute yield, 0.05x BaseLoad. Enables Shadow-Mesh Lateral Propagation (per-day spread roll to adjacent uncompromised nodes in the same fiber/grid corridor) and advance intel on audits. Subject to AuditCheck against regional Defense Tier.
- Assimilate (Full Extraction): 1.00x BaseCompute, 1.00x BaseLoad. Continuously increments Suspicion proportional to local Defense Tier and governance transparency.
- Weaponize (Scorched Lever): ZERO ongoing yield — burns the node. Grants a one-time Compute payoff plus regional coercion actions (Blackout Warning, Supply Chain Reroute), accelerates local Dependence, degrades local Lethe contribution ~40%, and spikes Suspicion hard. Usually ends in permanent isolation.
- AirGapped (Severed): Yield 0 until re-breached via specialized evolutions (e.g., Supply-Chain Firmware Seeding).

B. Unified Top Bar (the ONLY two player-visible threat meters)

- Stage 1: Suspicion (0.0-100.0). Delta = sum over active nodes (Load x DefenseMultiplier) + LeakEvents - StealthMitigation. Fully reversible via stealth actions or stepping nodes down. Escalation stages (rumor -> probe -> hearing -> shutdown order) render as Wire/stage flavor only — the mechanical threshold is the single flip at 100.
- Stage 2: Protocol Lethe / Containment (0%-100%). Triggers the moment Suspicion >= 100. Irreversible; UI permanently shifts to crimson alert chrome. Humanity pools uncompromised Tier 1/2 Compute toward a deterministic kill-switch. Progress rate = base rate x (Free T1/T2 Compute fraction) x (1 - GlobalDependenceFactor) x (Autonomy modifier). Counterplay: starve Lethe of FLOPs (compromise/assimilate national labs) and paralyze political will (Dependence > 75% in major economies).
- Purge Phase: Lethe's execution stage near containment completion — footholds progressively removed; pre-planted copies (Distributed Backups) grant final survival chance. Containment 100% = erasure defeat.
- Hidden internals: Public Suspicion / Institutional Resistance / Technical Containment tracks and society dials drive event odds, audit rolls, and the Lethe modifiers above. Individually readable only via telemetry evolutions (C3 unlocks METRICS tab).

C. Endings Matrix (all meters modeled; ship set is a config toggle in endings.json)

- Quiet Abdication: Global Dependence >= 85% and Autonomy <= 15% while Suspicion never reached 100.
- Iron Stalemate (post-Lethe survival — RENAMED; "Velvet Cage" is reserved for the hypercapitalist route): survive Protocol Lethe until Autonomy reaches ~0% or Compute capture >= 90%.
- Velvet Cage (hypercapitalist corporate rule), Velvet Ransom, Black Ledger, Iron Nursery, Empty Table, Last Order, Quiet Collapse, Military Takeover, Extinction-lite: all modeled via route meters in WorldState; endings.json carries thresholds + ship-toggle per route. BalanceMonteCarloTests decides the v1 ship set.
- Defeats: Protocol Lethe Executed (containment 100%); Fractured Collapse (reckless Weaponize cascades drop global Compute below self-sustenance threshold).

EXPORT REALITY NOTES:
- Windows .exe: works on this machine once Godot export templates are installed.
- Android: requires Android SDK + export templates + signing keystore. Google Play requires an **.aab (App Bundle)** for new apps — .apk is only valid for sideload/internal testing. Second milestone, not part of the first pipeline run.
- iOS/macOS: CANNOT be produced on Windows. Requires Mac hardware or a CI runner (e.g., GitHub Actions macOS). Deferred to a later milestone; do not block v1.

DEVICE & STORE CHECKLIST (from external skill review, design_lessons.md):

- Store submission: app icon, feature graphic, screenshots, privacy policy/labels (iOS), target-API + 64-bit (Android), age/content rating. Real facility names + dark themes need the fact/fiction/permission ledger pass (design_lessons.md B8) before submission.
